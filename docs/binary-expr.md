# Binary Expr

```lisp
(<op> <lhs> <rhs>)
```

## Add

```lisp
(+ <lhs> <rhs>)
; or
(add <lhs> <rhs>)

; Ex:
(+ 10 10)               ; 20
(+ "Hello" "World")     ; => "HelloWorld"
```

## Subtract

```lisp
(- <lhs> <rhs>)
; or
(sub <lhs> <rhs>)

; Ex:
(- 10 10)               ; 0
```

## Divide

```lisp
(divide <lhs> <rhs>)

; Ex:
(divide 10 2)               ; 5
```

## Multiply

```lisp
(* <lhs> <rhs>)
; or
(multiply <lhs> <rhs>)

; Ex:
(* 10 2)               ; 20
```

## Modulus

```lisp
(% <lhs> <rhs>)
; or
(mod <lhs> <rhs>)

; Ex:
(% 10 2)               ; 0
```
